# RE OS · 千禧年桌面解谜游戏外壳

一个仿 Windows 7 + 千禧年（Y2K / Frutiger Aero）风格的网页桌面外壳，包含四个可打开的程序与一张桌面便签。
**当前状态：只有外壳与占位内容，没有剧情。** 所有内容都集中在 `assets/js/data.js`，填剧情时只改这一个文件。

## 运行

直接双击 `index.html` 即可（纯静态、零依赖、零构建）。
如需局域网/手机访问，在该目录起个静态服务器：

```bash
python -m http.server 8080
```

## 目录结构

```
index.html                 页面骨架（开机动画 / 桌面 / 任务栏 / 开始菜单 / 屏保）
assets/css/core.css        系统外壳样式：壁纸、Aero 窗口、任务栏、开始菜单、屏保
assets/css/apps.css        四个程序各自的样式
assets/js/data.js          ★ 全部内容（聊天/网页/文件/照片）+ 图标 SVG
assets/js/wm.js            窗口管理器：拖拽、缩放、最小化、最大化、任务栏
assets/js/apps.js          四个程序的渲染与交互逻辑（含千度内的警局档案站子站）
assets/js/main.js          开机动画、桌面图标、开始菜单、时钟、屏保、右键菜单、桌面便签
```

## 本地存档与缓存

- 各脚本带 `?v=20261029a` 版本号（`index.html` 底部），改动后改这个串即可强制浏览器重新下载。
- ReChat 会校验本地存档里的账号：若指向已下线的账号（如旧版的 `chunchun`），自动回落到默认账号 `liu` 并写回，不会出现空白会话列表。
- ReChat 的 `mount()` 外层有 try/catch 兜底：万一渲染异常，会显示「本地存档与当前版本不兼容」并提供「清空本地存档并重新载入」按钮，不再白屏。
